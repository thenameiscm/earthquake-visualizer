# 🌎 Earthquake Visualizer

An interactive React + Tailwind + Leaflet web app that visualizes real-time global earthquake data from the USGS API.

## 🚀 Features
- Displays recent earthquakes on a world map
- Circle size and color represent magnitude
- Click markers for details (location, magnitude, time, link)
- Fully responsive and mobile-friendly
- Built using Vite + React + TailwindCSS + React-Leaflet

## 🧠 Data Source
[USGS Earthquake API](https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/all_day.geojson)
